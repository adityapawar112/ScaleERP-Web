# Project Brief: ScaleERP-Web

## Core Requirements & Goals
ScaleERP-Web is a modern web application designed with a high standard of visual excellence and dynamic design.
The goal is to build a highly responsive, premium-feeling application using the latest web technologies, including Shadcn UI components from Shadcn Space.

## Scope
- Initialize the scaffold directory structure using Vite (React + TypeScript).
- Configure styling with TailwindCSS (as required by Shadcn) and setup the Shadcn CLI.
- Build rich aesthetics with vibrant colors, dark mode, glassmorphism, and dynamic animations.
- Implement SEO best practices out of the box.
